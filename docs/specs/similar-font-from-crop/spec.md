# 크롭한 텍스트로 비슷한 무료 폰트 추천

## 개요

편집자가 레퍼런스 영상 스크린샷을 올리고, 그 위에서 텍스트 한 덩어리를 드래그로
선택하면, 앱이 시각적으로 비슷한 무료 폰트 후보를 정렬해 보여주고 각 후보의
다운로드 링크를 준다. `PRODUCT.md` 핵심 흐름을 한 번 도는 첫 세로 슬라이스다.

## 사용자에게 보이는 결과

- 편집자는 스크린샷을 올리고 앱 안에서 바로 텍스트 영역을 지정한다. 다른 툴에서
  미리 자를 필요가 없다.
- 지정한 영역과 비슷해 보이는 무료 폰트 후보 목록을 받는다.
- 각 후보를 자기가 입력한 글자로 렌더링된 상태로 비교하고, 마음에 들면 링크로
  바로 내려받으러 간다.

## 범위

포함:

1. 스크린샷 이미지 업로드(PNG/JPG).
2. 업로드한 이미지 위에서 드래그로 사각형 영역 1개 지정. 다시 그리기 가능.
3. 선택 영역의 글자를 편집자가 텍스트로 입력. 비워 두면 고정 샘플 문구 사용.
4. "추천" 실행 시 선택 영역과 시각적으로 비슷한 순으로 정렬된 무료 폰트 후보
   목록 제공.
5. 각 후보에 대해 폰트 이름, 입력한(또는 샘플) 글자를 그 폰트로 렌더링한
   미리보기, 다운로드 링크 표시.

제외(이유):

- 스크린샷에서 여러 텍스트를 자동으로 분리해 각각 추천 — 첫 버전에서 정확도가
  불안정해 "동작하는 결과물"을 흔든다. 다음 단계로 미룸.
- OCR로 글자 자동 인식 — 스타일이 강한 타이틀에서 실패율이 높음. 편집자 입력으로
  대체.
- OS별 설치 안내, 편집 프로그램 연동 — `PRODUCT.md` 경계.
- 계정, 로그인, 검색 기록 저장 — `PRODUCT.md` 경계. 매번 새로 진행.
- 한글 무료 폰트 후보 풀 — 첫 버전은 라틴(영문) 폰트 중심. 이후 확장.

## 수용 기준(관찰 가능)

1. 편집자가 PNG 또는 JPG 파일을 업로드하면 이미지가 화면에 표시된다.
2. 표시된 이미지 위에서 마우스 드래그로 사각형 영역을 그릴 수 있고, 다시 드래그하면
   이전 영역이 대체된다.
3. 텍스트 입력란에 글자를 넣을 수 있다. 입력이 비어 있으면 고정 샘플 문구가 대신
   쓰인다.
4. "추천"을 실행하면 무료 폰트 후보가 여러 개(기본 약 5개), 선택 영역과 비슷한
   순으로 정렬되어 나온다.
5. 각 후보 항목에 폰트 이름, 입력한(또는 샘플) 글자를 해당 폰트로 렌더링한
   미리보기, 다운로드 링크가 모두 보인다.
6. 다운로드 링크를 누르면 해당 무료 폰트를 받을 수 있는 외부 페이지가 새 탭으로
   열린다.
7. 페이지를 새로고침하면 업로드, 선택 영역, 추천 결과가 모두 초기 상태로 돌아간다.

## 확정한 제약과 근거

- 크롭은 앱 안에서 한다(드래그 박스). 편집자는 보통 전체 프레임을 캡처하므로 앱
  밖 사전 크롭은 `PRODUCT.md`의 "작업 흐름을 끊지 않는다" 원칙과 어긋난다.
- 미리보기 글자는 편집자 입력을 쓴다. 같은 단어로 렌더링해야 유사도 비교가
  정확하고, OCR보다 실패 지점이 적다.
- 추천 대상은 무료 폰트만(`PRODUCT.md` 경계).

## 가정(재검토 시 뒤집힐 수 있음)

- 무료 폰트 출처는 Google Fonts. 무료, 미리보기·다운로드가 쉬움. 다른 출처가
  필요하면 재검토.
- 후보 개수는 약 5개.
- 다운로드 링크는 해당 폰트의 Google Fonts 페이지로 연결.
- 입력 이미지 형식은 PNG/JPG.
- 첫 버전 후보 풀은 라틴 문자 폰트 중심.

## 미룬 항목

- 스크린샷 하나에서 여러 텍스트를 자동으로 분리해 각각 추천.
- 한글 무료 폰트 후보.
- 유사도 판별 기법 고도화.

## 남은 위험

- 유사도 랭킹을 어떤 기법으로 하는지는 이 스펙에서 정하지 않는다(`PRODUCT.md`가
  기법을 미룸). 스텁이나 단순 휴리스틱 수준이면 "정말 비슷하다"는 성공 신호를
  충족하지 못할 수 있다. 런타임 검증은 흐름 완주(업로드 → 영역 지정 → 글자 입력 →
  추천 → 정렬된 후보 목록 → 미리보기·다운로드 링크 동작)로 한정한다.
- 라틴 중심 후보 풀은 `PRODUCT.md`의 "한글 폰트도 포함" 범위와 일시적으로
  어긋난다. 한글 확장은 미룬 항목으로 남긴다.
